Figma Design Brief – Create Order Page

Objective:
Design a Create Order page in the same style as the Pharmacy SaaS Dashboard. Use the same colors, Sidebar, Navbar, and premium SaaS design. The page must be user-friendly, fast to use, and intuitive, even for staff entering orders quickly.

1️⃣ Layout & Structure

Sidebar & Navbar: Keep exactly the same as the Dashboard design.

Page Header: “Create Order” title, breadcrumb if needed.

Customer Selection: Dropdown or search field to select customer.

Order Details Section:

Date: Auto-filled with today’s date (editable if needed)

Discount: Input field

Payment Method: Dropdown (cash, card, etc.)

Paid Amount: Auto-calculated or input field

Items Table:

Columns: Product Name, Batch Number, Amount, Price, Discount, Total

Add Product:

Manual input by typing product name or batch number

Barcode input field: user can scan or type barcode to add product automatically

Ability to add/remove rows dynamically

Auto-filled Fields:

“Created By” or staff info comes from JWT, not manually entered

2️⃣ Style & Theme

Primary color: Pharmacy Green #0D7D6D

Soft mint or lighter green for accents, hover, and active states

Clean white / very light gray backgrounds

Rounded corners (16–24px), soft shadows, modern SaaS look

Typography: Inter / SF Pro style, clean and legible

Micro-interactions: hover effects on buttons, row addition/removal, barcode focus highlight

3️⃣ User Experience

Easy to use: Minimal clicks, logical flow

Barcode support: Users can type or scan barcode to add products

Responsive: Works well on desktop (desktop-first)

Error handling: Highlight missing required fields or invalid inputs

Summary / Total: Show real-time totals at the bottom of the page

✅ Summary

Build Create Order page consistent with existing Dashboard design

Sidebar & Navbar intact, premium SaaS style

Allow manual or barcode product entry

Auto-fill staff info from JWT

Items table dynamic and user-friendly

Clean, modern, and professional pharmacy theme
