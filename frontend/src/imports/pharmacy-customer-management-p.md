🎯 Prompt for Figma AI

Design a modern SaaS-style Customer Management System for a pharmacy inventory and sales application. The UI should be clean, minimal, professional, and enterprise-level. Use soft shadows, rounded cards (16–20px radius), clear typography hierarchy, and a light neutral color palette with subtle status colors (green, red, yellow, blue).

1️⃣ Customers List Page

Create a full-width responsive page with:

Header Section

Page title: Customers

Search bar (search by name or phone)

Filter dropdown:

All

Has Debt

No Debt

Inactive

Primary button on the right: + Add Customer

Main Content – Customers Table

Create a modern table with hover effects and soft row dividers.

Columns:

Customer Name (with avatar circle placeholder)

Phone

Total Orders

Total Purchased

Total Paid

Current Balance

Status

Balance styling:

Red = Customer owes money

Green = No balance

Blue = Credit balance

Status badge styles:

Green badge: Good

Yellow badge: Small Debt

Red badge: High Debt

Each row should be clickable and navigate to Customer Details Page.

2️⃣ Add Customer Modal

Design a centered modal with clean spacing.

Fields:

Full Name (required)

Phone Number (required)

Email (optional)

Address (optional)

Initial Balance (numeric input)

Notes (textarea)

Buttons:

Cancel (secondary)

Save Customer (primary)

Add a helper text under Initial Balance:
"Positive value means customer owes money. Negative value means customer has credit."

3️⃣ Customer Details Page

Create a structured layout divided into sections with tabs.

Top Section – Customer Summary Card

Include:

Avatar

Full Name

Phone

Email

Address

On the right side show financial summary:

Total Orders

Total Purchased

Total Paid

Current Balance (large, bold, color-coded)

Add buttons:

Edit Customer

Add Payment

4️⃣ Tabs Section

Create horizontal tabs:

Overview

Orders

Payments

Ledger

Overview Tab

Show financial statistics cards:

Last Order Date

Average Order Value

Largest Order

Payment Behavior (On Time / Late indicator)

Orders Tab

Table:

Order Number

Date

Total

Paid

Remaining

Status

Status badges:

Paid (green)

Partially Paid (yellow)

Unpaid (red)

Each order should be clickable.

Payments Tab

Table:

Payment Date

Amount

Payment Method

Notes

Ledger Tab (Professional Accounting View)

Create a clean accounting ledger table:

Columns:

Date

Description

Debit

Credit

Running Balance

Use subtle color coding:

Debit in red

Credit in green

Balance column bold.

5️⃣ Extra Professional Features

Include:

Credit Limit field in customer profile

Warning banner if customer exceeds credit limit

Timeline activity sidebar showing:

Customer created

Orders

Payments
